# Portfolio

My personal portfolio, built with Next.js and Tailwind CSS. Showcases my
projects, skills and experience as a Full-Stack Engineer.

## Stack

- Next.js
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Run locally

\`\`\`bash
npm install
npm run dev
\`\`\`

Then open [http://localhost:3000](http://localhost:3000).

## Structure

Content (projects, skills, services) lives in plain data arrays in each
section component, so updating the portfolio just means editing the data,
not the layout.
